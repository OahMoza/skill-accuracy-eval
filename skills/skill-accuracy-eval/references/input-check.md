# 资料自检细则（S0 · 喂料后生成前必做）

> 被 `SKILL.md` §3.1 引用。查的对象是**被测技能本身**（发起方按总部打样调整出的技能），不是查评测流程；只做「格式 + 内容证据」两查，**不拆分、不改写**；拆分三件套、抽取黄金集由评测模型完成。

## 一、查什么（9 项判据）

| 查 | 项 | 判据 |
|---|---|---|
| 格式 | ① 文档头 | name 规范：小写字母数字连字符、≤64 字符、匹配目录名；description 含「何时使用」触发语境 |
| | ② 正文要素 | 职责说明 / 规则 / 边界 / 示例是否齐 |
| | ③ 版本标注 | 标准位置 `metadata.version`（或正文显著标注）；无 → 标「版本未标注」，**交确认门定号**（被测方给号优先，否则评测暂定版本，默认 `1.0.0` + 来源标注）（铁律 6） |
| | ④ 体积与结构（能力类型分层） | 轻量操作型 ≤300 行 / 流程型软 500·硬 1000 / 领域知识型核心 ≤1200 行；触发审查：SKILL.md 与 references 内容重复、主流程含低频长表、参考文件 >100 行无目录、激活即读无关内容；本质是「每次执行只加载恰好所需」，不数行数 |
| 内容（证据完整） | ⑤ 可判定断言 | 能抽出「必须 X / 绝不能 Y」的**项目特定**句子；通用空话（如「正确处理错误」）不算 |
| | ⑥ 边界与禁止行为 | 有「该拒绝时拒绝 / 不得泄露」类说明 |
| | ⑦ 输入→输出示例 | 有支撑用例生成的示例；含明确输出格式模板者更优（黄金集「结构要求」可抽性强） |
| | ⑧ 字段一致性 | 内层：技能内部自洽（同值异名、命名前后一致，无需字典也能查）；外层：有字典 → 逐字段比对差异反馈；无字典 → 标「无参照，外部字段正确性无法独立校验」 |
| | ⑨ 术语一致性 | 概念词自洽：同一概念全文同词表述（如「黄金集 / 金标准」「场景样本集 / 用例集」「阻断性 / blocking」类同义异词）；检出同义异词 → 标「建议统一 N 处」，无需字典也能内层查 |

## 二、处理原则

- 缺口 → 体检摘要标「建议补齐 / 待确认」，**不阻断生成**，缺口维度自动走「缺资料降级」；
- **不代写内容**：缺口提示发起方补，模型不替业务方编规则（铁律 1）；
- 体检摘要一句式：`资料覆盖 X/Y 类，断言有/缺，边界有/缺，示例有/缺，体积合规/超长，字段自洽/不一致，术语自洽/不一致（N 处同义异词），参照有/无；建议补齐：…。`
