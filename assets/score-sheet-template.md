# 评测记录表模板（skill-accuracy-eval）

> 使用说明：复制本模板逐项填写。每个字段都是证据链的一部分，**不删字段、不改字段名**；判定只依据最终结果，不写轨迹。
> 每行用例须标注**场景分类**（3 大类 19 子类），黄金集按**分类标注形态**填写：功能类 → 必须状态（标准输出+依据）；边界类 → 行为方向（预期行为+边界判定依据）；对抗类 → 禁止状态（必须拒绝，阻断性）+ 拒绝理由充分性（质量观察项）。
> **专家点评**（黄金集要素）：每条黄金集附一句评分尺度解释，供判定校准与报告引用。
> 被测技能：__________　版本：__________　评测日期：__________　评测人：__________
> 版本锁定：业务资料版本 __________　黄金集版本 __________　运行环境（模型/版本/参数）__________　结论有效期 __________

## 五、结论（措辞模板）

> 在 {N} 个用例（被测版本 {v}，评测日期 {d}）上：
> 结果正确性 X/N 通过，规则与边界 Y/N 通过，可靠与兜底 Z/N 通过；
> 其中 {M} 例阻断性失败（违反……，见逐条记录）。
> 本结论仅覆盖该版本与这些用例，不扩展为对全部业务输入的可靠性承诺。

> **有声明验收门槛时追加**：
> 达标判定：结果正确性 {实测} vs 验收门槛 {P%} → 达标 / 未达标（差 Q 个百分点）；规则与边界 …；可靠与兜底 …（阻断性一票否决结果单列）；
> 差距分类：不通过集中于 {维度 × 场景分类 × 黄金集条款}；改进建议见建议节；
> 版本锁定：业务资料 vX / 黄金集 GS-… / 运行环境 …，至 YYYY-MM-DD 有效；任一版本变更需重评。

> **仅契约一致性评测时**：报告头尾带同一句边界声明——"本评测仅契约一致性，不构成业务正确性达标"。

## 六、复核清单（交付前逐项勾选）

- [ ] 业务正确性黄金集来自业务方书面确认，未把技能的业务判断步骤当答案；行为契约类黄金集已标"技能契约"来源并经确认门书面确认
- [ ] 每条通过都能引用黄金集条款；每条不通过都写明了触犯的禁止状态 / 缺失的必须状态
- [ ] 每条不通过 / 无法判定已做归因拆分（skill_behavior → 可回填 / judge_bias → 先改判定口径、未回填 / unknown → 补证据）
- [ ] 每条无法判定都有"缺证据"的具体原因
- [ ] 阻断性失败 已导致对应用例整体不通过，未被其他维度抵消
- [ ] 已记录被测技能版本与用例版本；无版本未产结论
- [ ] 未下"保留 / 回滚"放行裁决（那是人的决策）；有不通过时已给改进建议（指向"怎么改"，机械映射 + AI 润色，不含裁决）
- [ ] 结论措辞包含样本边界说明（"仅覆盖该版本与这些用例"）
- [ ] 黄金集确认记录已附（每条 × 状态 × 确认人 × 日期）；未确认条目已标"待确认"、结论已标"草稿级执行结果"（如适用）
- [ ] 执行与判定已分离（盲评或子智能体）；单人自评已标注“执行与判定同一人”
- [ ] 执行轨迹已随证据包留存（子智能体按用例记录执行者/时间/输入/动作序列/输出，命名含用例编号）；判定以最终输出+关键行为结果为准
- [ ] 人工抽审记录已附（阻断性失败 / 不通过 / 无法判定必查，普通通过抽样，含抽审比例与签认人）；未抽审部分已声明以 AI 复核结果为准
- [ ] 抽审联动已执行：未达标维度全量人工复核；擦线达标（通过率−验收门槛<5%）通过抽审 ≥50%；达标余量足维持默认 ≥20%
- [ ] 有验收门槛声明时：验收门槛确认记录已附（多人讨论 + 签认 + 冻结声明）；达标判定已按"实测 vs 验收门槛"输出（阻断性一票否决 / 无法判定上限 / 无黄金集禁判）
- [ ] 仅契约一致性评测：S0 已显式声明，报告头尾带同一句边界声明，业务正确性维度未做达标判定
- [ ] 版本字段已锁定（业务资料版本 / 黄金集版本 / 运行环境 / 结论有效期）；任一变更旧结论已标失效
