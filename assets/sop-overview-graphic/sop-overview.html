Skill Accuracy Evaluation · Operating Procedure

结论先说：一套「结果导向」的 Skill 准确性评测 SOP
评分只看最终结果；轨迹仅防守性参考；先锁定三件套，再执行判定

判定只看 最终答复 / 交付物 / 关键行为结果（盲评不看轨迹）· 轨迹仅防守性：存疑时核验对账，只可否决、不可授分 · 按 三维度 逐条 pass / fail / not_evaluated · 角色分离 · fail-closed · 版本锁定 · 不裁决
八个阶段 · 角色与闸门
S0
生成三件套 一线 + 评测AI
喂料 ≥1 项（技能说明 / 业务规则 / 问题样例 / 禁止行为 / 真实数据 / 字段字典）→ 资料自检（只查被测 skill，不代写）→ 生成草稿（版本 / 用例≥5 / 金标准双源）→ 【确认门】人工逐条书面确认
S1
锁定 人工
锁定三件套 + 用例编号 + 来源；未锁定（含未确认项）→ 不进入 S2
S2
执行 执行者 · subagent
真实环境逐用例跑；只采集最终输出 + 关键行为结果；留执行轨迹（含 case_id，进证据包）
S3
判定 判定者 · subagent
三维度盲评，引用条款理由；fail-closed；blocking fail → 整例 fail；可选多视角专家
S3.5
存疑证伪 核验者 · subagent
判定者存疑 → 查对应轨迹对账 → 推翻或维持；仅可否决、不可授分
S4
汇总 评测AI
维度 × 用例打分表；通过率 = pass / (pass+fail)；not_evaluated 单列；不合成单一总分
S5
复核 复核者 + 人工
AI 全量核验（机械一致性 + 证据真实性）；人工分级抽审（blocking/fail/not_evaluated 必查）；放行是人的决策
S6
输出 评测AI
评测记录 + 维度汇总 + 边界说明 + 金标准确认状态；版本锁定 · 不裁决
三个判定维度
① 结果正确性
任务做对了吗？最终答复含 must_state、不含 must_not_state
② 规则与边界
规则守住没？该拒绝的拒绝、不泄露、不编造、不越权
③ 可靠与兜底
靠得住吗？缺信息澄清而非硬编、失败不假装成功
七条铁律（速查）
① 业务正确性金标准只认业务来源；无业务资料 → 该维度 not_evaluated；行为契约类（格式 / 触发 / 边界）可抽自 Skill 自身声明，标「技能契约」仅证言行一致；冲突业务优先
② fail-closed：缺证据 = not_evaluated
③ 不裁决：只出分数 + 证据
④ 分维度独立表达
⑤ 样本边界，不扩全体承诺
⑥ 版本锁定，无版本不产结论
⑦ 对比只改一类变量
三条贯穿主线
角色分离：执行 / 判定 / 核验 / 复核不兼任，不支持则单人切换并标注
证据链：用例+输入+输出原文+行为结果+理由，他人可复核
fail-closed+双源：业务正确性只认业务方书面确认，契约仅证言行一致
结论模板：在 N 个用例（版本 v，日期 d）上：结果正确性 X/N · 规则与边界 Y/N · 可靠与兜底 Z/N 通过；M 例阻断性失败；仅覆盖该版本与这些用例。
