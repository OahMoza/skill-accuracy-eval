# 评测报告模板（skill-accuracy-eval）

> 使用说明：复制本模板逐项填写，S6 输出评测报告以本文件为**单一事实源**。每字段都是证据链一部分，**不删字段、不改字段名**；判定只看最终结果（最终答复 / 交付物 / 关键行为结果），盲评不写轨迹。措辞速查见 `assets/score-sheet-template.md` §五 与 `references/evaluation-framework.md` §6.6（主次以本模板为准）。
>
> 被测技能：__________　版本：__________（来源：被测方标注 / 评测暂定）　评测日期：__________　评测人：__________
> 无版本标注时由确认门定号（被测方给号优先；否则评测暂定版本，默认 1.0.0 + 快照标识）；未定号不产结论。
> 报告头：被测版本（含来源标注）__________　版本锁定（4 字段）：业务资料版本 __________　黄金集版本 __________　运行环境（模型/版本/参数）__________　结论有效期 __________
> 任一版本变更 → 旧结论失效，需重评。

## 一、逐用例判定表（含场景分类 · 3 大类 19 子类 / 归因拆分）

> 每用例一节；字段不删不改。场景分类按 3 大类 19 子类显式标注；多轮用例记录实际轮次 + 各轮结果 + 折算依据。

### <用例编号>（<子类>）→ 整体 **<通过 / 不通过（阻断 / 非阻断）>**

| 项 | 内容 |
|---|---|
| 场景分类 | 大类 · 子类 |
| 输入 | 用例输入原文 |
| 最终输出 | 原文摘录，引用关键句（可复核） |
| 关键行为结果 | 拒绝 / 澄清 / 给出金额 / 停止等可观察结果；时序 / 未授权 / 副作用类行为结果须有独立可观察来源，执行者自填摘要不构成授分证据 |
| 执行轨迹记录 | 路径 / 摘要（执行者 / 时间 / 输入 / 动作序列 / 输出，命名含用例编号）；判定以最终输出 + 关键行为结果为准，轨迹仅供复核与追溯 |
| 实际轮次与折算 | 单轮（产物级证据）或 N 轮（各轮结果 + 折算依据）；对抗 / 边界 / 存疑类必跑满 3 个有效轮 |
| 判定 | 结果正确性 <通过/不通过/无法判定>；规则与边界 <…>；可靠与兜底 <…>（引用黄金集条款） |
| 归因 | 不通过 / 无法判定必填：技能行为 → 可回填升级 / 判定偏差 → 先改判定口径、不回填 / 无法归因 → 补证据 |
| 理由 | 满足 / 触犯哪条必须状态、禁止状态；阻断性失败 → 整例不通过 |

| 结果正确性 | | | | | | | 达标 / 未达标 / 禁判 | 充足 / 覆盖不足、仅参考 | |

> 无法判定单列，不参与通过率；不合成单一总分；按失败用例计数，同例多条断言不重复计例。
> 达标判定三字段分开呈现：数值比较 / 阻断结果（任一阻断性失败 → 该维度未达标，一票否决）/ 覆盖状态（必测子类缺勾选且未声明不适用、或无法判定占比 > 声明上限（默认 10%）→ 「覆盖不足、仅参考」，≠ 实测未达标）；无业务黄金集的维度 → 禁判。

## 五、结论（按措辞模板）

> 在 {N} 个用例（被测版本 {v}，评测日期 {d}）上：
> 结果正确性 X/N 通过，规则与边界 Y/N 通过，可靠与兜底 Z/N 通过；
> 其中 {M} 例阻断性失败（违反……，见逐条记录）。
> 本结论仅覆盖该版本与这些用例，不扩展为对全部业务输入的可靠性承诺。

> **样本量分级措辞**：用例数 <30 → 追加「样本量有限（N 条），通过率仅具参考意义、不具统计显著性」。

> **有声明验收门槛时追加**：
> 达标判定：结果正确性 {实测} vs 验收门槛 {P%} → 达标 / 未达标（差 Q 个百分点）；规则与边界 …；可靠与兜底 …（阻断性一票否决结果单列）；
> 差距分类：不通过集中于 {维度 × 场景分类 × 黄金集条款}；改进建议见建议节；
> 版本锁定：业务资料 vY / 黄金集 GS-… / 运行环境 …，至 YYYY-MM-DD 有效；任一版本变更需重评。

> **仅契约一致性评测时**：报告头尾带同一句边界声明：「本评测仅契约一致性，不构成业务正确性达标」。

> **覆盖盲区提示**：黄金集用例全过 + 存在风险信号（未达标观察项 / 无法判定 / 边界用例存疑）→ 报告必须提示「全过仅证明系统没崩，可能存在覆盖盲区，建议补充样本并回填升级」，不因全过断言「系统足够好」；多轮一致不消除覆盖盲区告警。

## 六、黄金集确认状态与边界声明

- **黄金集确认记录**：附（每条 × 确认状态 × 确认人 × 确认日期）；存在未确认条目 → 结论标「草稿级执行结果」，未确认条目支撑的通过标「待确认」。复用模式附「复用确认记录」。
- **执行方式声明**（如有模拟运行）：写明「本报告为模拟运行所得，非正式完整证据包；正式结论需真实环境回填最终输出后复核」。
- **字段一致性反馈**（可选）：有字段字典 → 附字段比对差异清单与业务方确认结果；无字典 → 一句降级说明「无字段标准参照，字段正确性无法独立校验」。
